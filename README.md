## Weekly Summary

### Week 1 - HTML Fundamentals
A simple HTML webpage that introduces the branding of MATCHAHOLIC. It provides a brief description of what MATCHAHOLIC is all about. 

### Week 2 - Semantic & Multimedia
Introduces the creator of MATCHAHOLIC by showcasing the personal interests, likes, and preferences. It gives visitors a glimpse into the person behind the brand through a webpage featuring semantic HTML elements and multimedia content.

### Week 3 - CSS Basics
The first version of the MATCHAHOLIC website, built from scratch using HTML and CSS. It introduces the basic layout and structure of the brand's webpage, featuring common sections such as About Us, Services, and Contact Us which serves as the starting point for the website's overall design and development.

### Week 4 - JavaScript Basics and DOM Manipulation
It focuses on enhancing the MATCHAHOLIC website by adding interactive features using JavaScript and DOM manipulation. The webpage now includes a live clock, a theme switcher, keyboard events, and a task form where users can enter and submit their tasks which make the website more dynamic and engaging.

### Week 5 - Javascript Functions and Bootstrap
The polished version of the MATCHAHOLIC website, featuring an improved layout and a more refined design with Bootstrap. Visitors can explore the brand's story, learn about its offerings, and discover the different matcha flavors available, along with their respective prices. The website also features a more organized and responsive layout for a better browsing experience.

### Week 6 - API & Client Storage
This version introduces more advanced features to the MATCHAHOLIC website through APIs and client-side storage. It includes local storage for saving data, user preferences for customizing the browsing experience, a weather feature, an interactive map, and a GitHub username search feature. 

### Week 7 - MiniFullStackStarter
This is the final version of the MATCHAHOLIC website, now enhanced with full-stack functionality. It uses MongoDB to store user-submitted data, including names, ages, and email addresses. Users can add their information and delete submitted records, demonstrating how the website can interact with a database and manage stored data.
